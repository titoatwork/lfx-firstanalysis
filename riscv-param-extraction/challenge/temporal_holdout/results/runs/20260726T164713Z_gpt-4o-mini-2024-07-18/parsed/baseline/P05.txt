```yaml
- $schema: param_schema.json#
  kind: parameter
  name: SUM
  long_name: Supervisor User Memory Access
  description: |
    The SUM (permit Supervisor User Memory access) bit modifies the privilege with which S-mode loads and stores access virtual memory. When SUM=0, S-mode memory accesses to pages that are accessible by U-mode will fault. When SUM=1, these accesses are permitted. SUM has no effect when page-based virtual memory is not in effect. While SUM is ordinarily ignored when not executing in S-mode, it is in effect when MPRV=1 and MPP=S. SUM is read-only 0 if S-mode is not supported or if `satp`.MODE is read-only 0.
  definedBy: extension: { name: S }
  schema: { type: boolean }

- $schema: param_schema.json#
  kind: parameter
  name: MBE
  long_name: Memory Access Endianness for M-mode
  description: |
    The MBE bit in `mstatus` controls whether non-instruction-fetch memory accesses made from M-mode are little-endian (MBE=0) or big-endian (MBE=1). The MBE field is a WARL field.
  definedBy: extension: { name: Sm }
  schema: { type: integer }

- $schema: param_schema.json#
  kind: parameter
  name: SBE
  long_name: Memory Access Endianness for S-mode
  description: |
    If S-mode is not supported, SBE is read-only 0. Otherwise, SBE controls whether explicit load and store memory accesses made from S-mode are little-endian (SBE=0) or big-endian (SBE=1). The SBE field is a WARL field.
  definedBy: extension: { name: S }
  schema: { type: integer }

- $schema: param_schema.json#
  kind: parameter
  name: UBE
  long_name: Memory Access Endianness for U-mode
  description: |
    If U-mode is not supported, UBE is read-only 0. Otherwise, UBE controls whether explicit load and store memory accesses made from U-mode are little-endian (UBE=0) or big-endian (UBE=1). The UBE field is a WARL field.
  definedBy: extension: { name: S }
  schema: { type: integer }
```
