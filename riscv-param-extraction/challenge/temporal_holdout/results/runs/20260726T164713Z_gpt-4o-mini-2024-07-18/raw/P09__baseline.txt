```yaml
- $schema: param_schema.json#
  kind: parameter
  name: FRACTIONAL_LMUL_SUPPORT
  long_name: Fractional LMUL Support
  description: |
    Implementations must provide fractional LMUL settings that allow the
    narrowest supported type to occupy a fraction of a vector register
    corresponding to the ratio of the narrowest supported type's width to
    that of the largest supported type's width. In general, the
    requirement is to support LMUL {ge} SEW~MIN~/ELEN, where SEW~MIN~ is
    the narrowest supported SEW value and ELEN is the widest supported SEW
    value. For standard vector extensions with ELEN=32, fractional LMULs of
    1/2 and 1/4 must be supported. For standard vector extensions with
    ELEN=64, fractional LMULs of 1/2, 1/4, and 1/8 must be supported.
  definedBy: extension: { name: Zvl32b }
  schema: { type: boolean }

- $schema: param_schema.json#
  kind: parameter
  name: SEW_SETTINGS_SUPPORT
  long_name: SEW Settings Support
  description: |
    For a given supported fractional LMUL setting, implementations must support
    SEW settings between SEW~MIN~ and LMUL * ELEN, inclusive.
  definedBy: extension: { name: Zvl32b }
  schema: { type: boolean }

- $schema: param_schema.json#
  kind: parameter
  name: LMUL_ENCODING
  long_name: LMUL Encoding
  description: |
    LMUL is set by the signed `vlmul` field in `vtype` (i.e., LMUL =
    2^`vlmul[2:0]`^).
  definedBy: extension: { name: Zvl32b }
  schema: { type: integer }
```
